# EnglishRPG

Edukacyjna gra RPG stworzona w ramach pracy inżynierskiej.

## Opis
EnglishRPG to dwuwymiarowa gra edukacyjna typu RPG, zaprojektowana w celu
wspierania nauki słownictwa języka angielskiego u dzieci poprzez
interaktywną rozgrywkę.

## Zastosowane technologie
- RPG Maker MZ  
- JavaScript  

## Cel projektu
Projekt został zrealizowany w celach dydaktycznych jako część pracy
inżynierskiej i stanowi przykład wykorzystania mechanizmów gier
komputerowych w procesie nauki języka obcego.

# EnglishRPG

Educational RPG game created as part of an engineering thesis.

## Description
EnglishRPG is a 2D educational role-playing game designed to support
English vocabulary learning for children through interactive gameplay.

## Technologies
- RPG Maker MZ
- JavaScript

## Purpose
The project was created for academic purposes as part of an engineering thesis.
